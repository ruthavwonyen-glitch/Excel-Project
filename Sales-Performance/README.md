
📊 Sales Dataset – Excel Practice Workbook

A synthetic sales dataset designed for practicing Microsoft Excel, data modeling, PivotTables, charts, and interactive dashboards.

The workbook contains three clean, relational tables that can be used for Excel analysis, business reporting, and forecasting exercises.

📁 Dataset Overview

The workbook includes three linked tables with no blank values or duplicate records and consistent data types.

Table	Records	Description	Table Type
Sales	1,200 transactions	Sales transactions from January 2024 to December 2025	Fact table
Products	16 products	Products across 4 categories	Lookup table
Customers	80 customers	Customers across 4 regions	Lookup table

Dataset Highlights
Date range: January 2024 – December 2025
Total transactions: 1,200
Total products: 16
Total customers: 80
Product categories: 4
Customer regions: 4

Data quality: No blanks or duplicates; consistent data types
Currency: A single currency throughout the dataset
Data type: Synthetic data for educational and practice purposes

🔗 Data Model & Relationships
The workbook supports relational data modeling through the following table relationships:

text
Customers                     Products
    │                             │
    │ CustomerID                  │ ProductID
    ▼                             ▼
    └──────────── Sales ──────────┘
                 Fact Table


Relationship definitions:

Sales[CustomerID] → Customers[CustomerID]
Sales[ProductID] → Products[ProductID]

Each lookup table provides descriptive information for analyzing sales transactions.

Recommended approach: Load all three tables into the Excel Data Model using Power Pivot and create relationships between the tables. Alternatively, use the calculated lookup columns in the Sales table directly for standard PivotTable analysis.

🧮 Calculated Columns

The Sales table includes formula-driven calculated columns for financial analysis, classification, and time-based reporting.

Column	Purpose
Gross Sales	Sales value before applicable discounts
Net Revenue	Revenue after applicable discounts
Total Cost	Total cost associated with the transaction
Profit	Profit generated by the transaction
Category	Product category associated with the sale
Segment	Customer or sales segment classification
Region	Customer's geographic region
Year	Transaction year
Month	Transaction month
Quarter	Transaction quarter

These columns make it easier to analyze revenue, profitability, customer segments, product performance, and sales trends over time.

🎯 Suggested Excel Exercises
1. Data Modeling & Forecasting
Forecast 2026 revenue using historical sales data.
Apply different revenue growth assumptions.
Evaluate the impact of discount percentage changes on net revenue and profit.
Perform what-if analysis using Excel's Scenario Manager or Data Tables.
Compare forecasted revenue against historical performance.
2. PivotTables & Business Analysis

Practice creating PivotTables to answer business questions:

Revenue by Category × Year: Compare category performance across 2024 and 2025.
Profit by Region: Identify the most profitable regions.
Top 5 Customers: Rank customers by net revenue or profit.
Sales Rep Ranking: Compare sales representatives by revenue, transactions, or profitability.
3. Charts & Data Visualization

Build charts that communicate key business insights:

Monthly revenue trend using a line chart.
Revenue share by product category using a doughnut or pie chart.
Regional performance using a bar or column chart.
Sales channel mix using a stacked column chart or doughnut chart.
4. Interactive Excel Dashboard

Build an interactive dashboard with KPI cards, charts, and slicers.

Recommended KPI cards:

Total Revenue – Sum of Net Revenue
Total Profit – Sum of Profit
Profit Margin (%) – Total Profit ÷ Total Net Revenue
Total Orders – Count of transactions, using a distinct count if multiple rows can represent one order

Recommended slicers:
Year
Region
Category

Connect the slicers to the relevant PivotTables and PivotCharts so users can interactively explore sales performance.
